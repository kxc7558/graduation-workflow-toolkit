## What This Is

A curated set of Claude Code skills I developed while building my graduation project — a full-stack logistics fund management system (Spring Boot + Vue 3 + Solidity + thesis).

16 raw skills were refined into **5 battle-tested skills** covering the complete workflow.

## Skills

| Skill | Use When |
|-------|----------|
| **`backend-dev`** | Writing Spring Boot controllers, MyBatis-Plus queries, REST APIs |
| **`blockchain-dev`** | Solidity contracts, Hardhat deployment, Web3j integration |
| **`frontend-pro`** | Vue 3 components, Element Plus styling, composables |
| **`code-quality`** | Auto-catches bugs, perf issues, security flaws in any file |
| **`thesis-tools`** | Writing thesis chapters, generating docs from code, Word automation |

## Installation

```bash
# Copy skills to your Claude Code project
cp -r skills/ your-project/.claude/skills/

# Or symlink
ln -s $(pwd)/skills your-project/.claude/skills
```

Skills activate automatically — no manual invocation needed.

## The Project This Built

- **Backend**: 14 controllers, 16 tables, JWT auth, RBAC, approval engine
- **Frontend**: 27 views, 23 components, AI chat panel, blockchain browser
- **Blockchain**: Solidity fund ledger, tx_hash auditing, snapshot recovery
- **AI Integration**: Ollama + OpenAI-compatible in-app assistant
- **Thesis**: 15,000 words, 7 chapters, school-format compliant
